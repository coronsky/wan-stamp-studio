# 05 テスト計画

状態: **設計案（承認待ち）** / 原則: 機能ごとにテストし、結果と**未検証事項**を TASKS.md と報告に記録する。

## 1. テスト層
| 層 | ツール | 対象 |
|---|---|---|
| 単体（Python） | pytest | 分割・端数・透過検査・文字描画・規格検査・パス処理・マイグレーション |
| API | pytest + FastAPI TestClient | CRUD、状態遷移、エラー応答 |
| 単体（TS） | Vitest | 企画表ロジック、プロンプト整形 |
| E2E | Playwright（Windows 実機 Edge/Chrome） | 主要フロー、レスポンシブ |
| 実機手動 | チェックリスト | Windows 11、日本語パス、iPad/iPhone 表示 |

## 2. 重点テスト項目
### 基盤
- 起動: `start.bat` で 127.0.0.1 のみ待ち受け（`netstat` で 0.0.0.0 でないこと）
- `stop.bat` が自アプリのプロセスだけ停止（他の Python/Node を止めない）
- 日本語・空白入りパス（例: `C:\Users\…\ドキュメント\ワン スタンプ`）で保存・読込・書出し
- マイグレーション: 旧版 DB → 新版適用で既存データが保持される、適用前バックアップが作られる
- APIキーがログ・レスポンスに出ない（ダミーキーで grep 検証）

### 画像処理
- 4×3 分割: 既知寸法の合成画像で各セル座標が正確
- 端数バッチ（例: 24 個 → 12+12、30 → 12+12+6）の行列計算
- 境界を手動で動かしたときの再分割
- 透過: 実アルファを保持、チェッカー柄が焼き込まれていない（ピクセル検証）
- 白い毛・白縁: 白背景除去テストでエッジ保持（自動結果は提案、手動修正後に確定）
- 文字合成: 日本語フォント（権利クリアなテスト用フォントのみ）、縁・位置、プレビューと出力の一致
- Undo/Redo: 履歴の巻き戻し、元画像が不変（sha256 一致）

### 規格検査（STAMP_RULES 暫定規格。実装前に LINE 公式ガイドラインを再確認）
- 個数 8/16/24/32/40 以外は出力不可
- PNG、最大 370×320、main 240×240、tab 96×74、縦横偶数、各 1MB 以下、約 10px 余白、連番 `01.png`〜
- 違反ケースごとにエラー/警告が正しく出る

### 品質・承認
- 機械検査 OK でも未承認なら出力不可
- 却下 → 再加工/再生成導線

### 出力
- ZIP の内容・命名・出力先選択、同名ファイル既存時の上書き確認（既存データ破壊防止）

### UI
- 空/読み込み中/失敗/再試行の各状態
- レスポンシブ（幅 390 / 820 / 1280）、キーボード操作、タッチ操作
- 感嘆符警告
