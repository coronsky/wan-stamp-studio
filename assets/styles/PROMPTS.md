# 画風サンプル画像 制作用プロンプト（ChatGPT用）

**制作済み（2026-11-15）**: 01〜30 は、下の方式（横3列×縦2行の6画風シート×5枚）で生成し、分割して384×384のPNGで登録済み。作り直すときの手順として残す。

## 方式
- ムーンの写真を添付し、共通指示を1回送ってから、シート1〜5（各6画風）を1つずつ送る。
- 出力はシートを3×2で等分割（シートの並び＝画風番号の順：左上→右、次の段）。
- 元のムーン写真は公開リポジトリに置かない。

## 共通指示（最初に1回）
```
添付写真の左側の白いビションフリーゼ（名前はムーン）だけをモデルにして、画風サンプルシートを5枚、1枚ずつ作ります。右側の別の犬は描かないでください。
・1枚に横3列×縦2行の等間隔グリッドで6マス、左上から右、次に下の段の左から右へ指定順に配置
・各マスに同じムーンを指定画風で1匹ずつ、正面おすわり・口を軽く開けた笑顔、全身を中央に、余白を十分に
・顔立ち、白いふわふわの巻き毛、黒い目と黒い鼻、耳、体型を写真に忠実に。服・リード・首輪・小物は描かない
・背景は全マス白一色。枠線・区切り線・影・文字・番号・ロゴ・署名は入れない
```
