# 画風サンプル画像 制作用プロンプト（ChatGPT用）

ムーン（白いビションフリーゼ）の写真を添付し、下の【共通指示】＋各画風を貼って1枚ずつ生成します。

## 共通指示（毎回、先頭に付ける）

```
添付写真の【左側の白いビションフリーゼ（ムーン）だけ】をモデルにしてください（右側の別の犬は描かない）。顔立ち・白いふわふわの巻き毛・黒い目と黒い鼻・耳・体型を忠実に維持し、服・リード・首輪・背景小物は描かない。
構図：正面向きのおすわり、笑顔（口を軽く開けた明るい表情）、全身が入る正方形（1:1）、中央配置、周囲に十分な余白。
背景：白一色（または透明）。影・床・文字・番号・枠線・ロゴ・署名は入れない。
画風：（下の各画風）
```

## 保存ルール

- ファイル名は番号2桁＋.png（`01.png` 〜 `30.png`）。**下の順序を変えない**（アプリの画風番号と一致させる）。
- 正方形、512×512 前後、PNG、1枚 約500KB以下を目安。白または透明背景。文字・番号なし。
- **元のムーン写真は公開リポジトリに置かない**（このフォルダには生成サンプルのみ）。
- 1枚ずつ確認し、ムーンに似ていない・服が付いた・別の犬になった場合は作り直す。
